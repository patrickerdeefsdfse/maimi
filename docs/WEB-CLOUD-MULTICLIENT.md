# 网页入口与同员工多端云工作区

2026-09-22：公司r12已部署；候选r13按用户确认将登录改为IAM单点取Key后由麦米维持24小时，网页/桌面仍各自拥有独立会话。正式IAM目标为 https://iam.megmeet.com，本地合成服务仅用于验证代码。

- IAM 首页 `/maimi/` 同时提供网页版和 Windows 下载入口。网页先在
  `/maimi/web/` 检查本人的麦米会话Cookie，再连接个人云端；不暴露本机目录。
- OAuth 只允许固定的 `return_to=/maimi/web/`，并把目标标记绑定到当前 OAuth
  流程。原桌面授权码交接保持独立，IAM token 和个人 TokenKey 不交给浏览器。
- 桌面和网页各自持有独立登录会话。Gateway 对 Cookie 原生请求的写操作与
  WebSocket 握手校验精确 Origin，持续复查会话。网页退出只撤销网页会话。
- 公司新会话在登录时验证IAM并取得个人Key/模型目录，随后仅复验麦米会话，
  默认24小时绝对截止、不因IAM短令牌到期而退出；到期需重新IAM授权。
- 员工稳定工号仍决定同一工作区和同一组持久卷。第二个客户端打开云端不重建
  已运行 Host；Host 心跳采用有效客户端期限的最大值，不延长客户端自身登录。
- 当前支持同员工多端同时连接、查看历史和文件；每个员工 Host 同时只运行
  一段云对话。另一端或另一段对话发送时显示忙碌提示，任务完成后即可继续。
  这也是当前文件写入的保守并发边界，不能称为多端协同编辑或离线同步。
- 每段任务固定使用发起端的服务器租约。模型代理不借用其他已登录端凭据；
  发起端退出或失效后，取消该任务、清除排队输入，保持 Host 与其他端连接。
  已发出的外部请求无法撤回；不以退出承诺撤销已经完成的操作。
- 云端工具通过本条会话的显式插件选择生效。本机电脑控制仅桌面提供。
  写操作确认经过独立 UI 路由：Gateway 生成绑定发起端租约和操作的一次性
  30 秒凭据，模型调用接口无法生成或代替此凭据。
- 云端不提供跨登录的后台任务委托。日程/目标/动态执行入口受限；工作流和
  上游原生插件的变更须继续审核，不能把共享 Host 当成无限期员工授权。

## 接入位置

`personal_cloud_web.py` 提供网页入口、原生资源和 HTTP/WebSocket 路由。
`personal_cloud.py` 保留员工身份、租约与模型代理边界；manager 只负责固定镜像、
资源限制和持久卷。独立 `task-authority.mjs` 和 `task-control-plugin.mjs` 实现
任务归属与原生活动状态观察；DSH 专属接口集中在薄插件内。

原生前端使用根路径资源，Nginx 模板新增 `/api/`、`/plugins/`、`/ext/`、
`/assets/`、`/__megmeet/` 及图标/manifest 转发，同时保留更具体的 `/maimi/web/`。
这些路径均由 Gateway 验证本人身份；不能转发到共享无身份 Host。

## 验证边界

新增测试覆盖独立 Cookie/桌面租约、过期/注销/身份变更、不重建同员工 Host、
真实 ASGI WebSocket 的单端注销与另一端存活、跨站握手拒绝、OAuth 固定跳转、
任务生成互斥、私有控制路径隔离、一次性确认凭据绑定与重复消费拒绝。

本地合成验证不代表真实公司 IAM/TokenKey、Nginx 入口或容量验收。默认仍是
两个活动个人 Host，每个 1536 MiB / 1 CPU；已有持久卷与历史数据不迁移不删除。

实际联调证据：`output/web-cloud-20260920/resume-web-chain.json`，32项通过，包含首页双按钮、网页Cookie与桌面授权、真实alpha.2聊天轮次与工具写文件、两端共享、跨员工隔离、根路径与桌面路径WebSocket、退出只断本端连接、重新登录重用同一Host。测试用独立合成Compose项目与数据卷，未复用公司账号或现有开发卷。`dev-local/nginx.conf`已补根`/api/remote.mux`的Upgrade转发，正式Nginx模板原有对应规则保留。
