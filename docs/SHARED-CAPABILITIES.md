# 企业项目共享平台能力

企业项目不再复制一套 Agent 或模型服务。项目通过 `project_key` 关联统一平台，并共享以下能力：

- DSH Adapter：普通对话、流式输出、会话恢复和 runtime 生命周期。
- Model Catalog：项目可设置默认 provider/model，但只能选择平台已启用且组织可见的模型。
- PostgreSQL：项目成员、会话、消息、插件授权、知识库关系、任务和审计统一存储。
- Redis：缓存、限流、队列和租约统一使用，不能作为唯一事实来源。
- Plugin Host：项目只声明启用哪些插件和权限，插件执行仍经过统一 broker。
- File/Knowledge：文件和知识库使用统一授权、哈希、版本和索引状态。

项目请求必须由服务端根据 SSO 用户和组织上下文解析成员关系；不能相信浏览器直接传入的组织或角色。普通聊天不自动加载项目插件，只有明确的项目/插件/文件上下文才进入企业能力链路。

项目会话仍出现在统一历史页，列表显示项目名称、插件入口和过期时间。项目管理员可设置本项目的保留天数和消息上限，用户也可在权限允许时为单个会话设置更短期限；系统定时清理过期会话和消息。
