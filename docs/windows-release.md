# Windows 版更新

更新源位于部署方网关的 `/maimi/updates/windows/` 路径，站点域名在构建时配置。0.14.0 及以后使用软件内「检查更新」。当前发布渠道用 HTTPS 和 SHA512 校验安装包。安装程序签名和依赖清单见[桌面发行记录](../desktop/README.md)。

1. 提升麦米桌面版本，独立记录 DSH 运行时版本和企业插件版本。
2. 使用同一最终构建生成 `Maimi-Setup-<版本>-x64.exe`、同名 `.blockmap` 和 `latest.yml`。
3. 核对清单中版本、文件名、长度、SHA512 与真实安装文件。已有版本号不能换包。
4. 两个 AP 先就位安装器和差分文件，再切换各自的 `latest.yml`。版本清单每次检查都重新读取，已发布安装包保留以支持老客户端升级。
5. 从正式域名验证两台 AP 的清单、断点请求、完整文件摘要及首页入口。使用隔离的旧版本客户端验证发现新版、下载、校验和安装确认。记录真实员工电脑上的安装结果。

用户插件位于独立配置目录。构建和升级时只更新公司管理的默认资源，保留用户安装的插件、设置和文件。未经员工选择不要清理用户目录。0.13 及以前渠道的用户首次手动安装当前版。
