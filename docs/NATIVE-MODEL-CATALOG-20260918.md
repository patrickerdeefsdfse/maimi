# 原生桌面个人模型与新会话验证

本地范围；未访问公司IAM、TokenKey或长沙服务器。

## 模型目录

网关按当前登录员工的IAM身份读取个人TokenKey授权目录。桌面将目录中的所有获准模型交给原生DSH模型菜单；如管理员另有全局允许列表，服务端取二者交集。模型调用仍逐次由服务端验证，修改浏览器请求不能增加模型权限。

DS4.1已授权时启动/刷新默认选择`deepseek-flash-v4.1`。未授权时使用实际目录内模型，并返回明确中文说明；没有模型时拒绝启动模型会话。原生会话已有的显式模型选择保留，刷新不强制改写历史或正在打开的会话选择。

- `GET /__megmeet/desktop/models`：当前本人目录、默认模型、首选模型是否获授权及说明。
- `POST /__megmeet/desktop/models/refresh`：只接受本机桌面会话Cookie与相同Origin，重新取得本人目录，通过版本固定的原生`settings/update`更新模型配置，利用原生事件刷新模型菜单。无需重启Host。
- 退出/过期会话不能刷新目录；目录变化不会绕过服务器当前授权检查。

模型目录和本机代理URL可进入本人原生设置文件；个人TokenKey和公司服务密钥不会进入模型菜单、浏览器或设置文件。

## 新会话

原生0.1.6-alpha.1实际浏览器验证：创建首个工作区后，顶部“新会话”能创建并打开可编辑会话；发送一轮后再次点击能创建新会话。原生DSH会复用同工作区尚未发送的空白草稿，因此再次点击空白会话时画面原本没有明显变化。

保留原生草稿语义，在受原始摘要保护的workspace适配中增加打开中、完成、缺工作区和失败提示，完成后聚焦原生输入框。没有另建聊天UI，也不清空未发送草稿。

## 证据

`desktop-local/scripts/native-navigation-model-probe.cjs`使用一次性合成Windows目录、真实DSH Host及隐藏Electron浏览器。它实际点击原生模型菜单选GLM、发送消息，核对合成个人模型代理收到的模型为`glm-5.3-flash`，再验证新会话与动态目录增加/删除、首选未授权提示和拒绝跨源刷新。证据位于`desktop-local/evidence/navigation-model/`。

该探针使用明确的合成模型响应，不代表公司模型调用已联调。`dev-local/dsh/test-workspace-pinned-overlay.mjs`验证新会话反馈、失败/空目录分支、卸载后不误聚焦及适配后的原生模块语法。最终打包后仍需按该版本的实际运行证据判断，不能用静态构建代替验收。
