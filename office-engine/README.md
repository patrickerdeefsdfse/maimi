# 麦米办公扩展 1.0

这是一套独立办公引擎，使用 `megmeet-office-v1` JSON 协议。DSH 只通过三个适配器文件调用它；Python、文档库、离线 OCR 和 LibreOffice 随产品交付，不依赖员工预装 Office/Python，不改动 DSH 核心。

## 员工如何使用

先按 DSH 原生方式选择本地或个人云端工作区，然后直接附加文件或提到工作区内的文件。例如：

- “总结这份 PDF，标明页码；扫描页请识别文字。”
- “把这个 Word 中的旧项目名称替换为新名称，另存为修订版.docx。”
- “整理 Excel 销售表，计算部门合计并生成柱状图，另存为分析.xlsx。”
- “识别截图中的文字”“合并这两份 PDF”“把报告转成 PDF”。

办公工具是 DSH 原生工具列表的一部分，不需要员工单独选择或配置 API key。模型先查询 `office_capabilities` 获取操作参数；会话附件必须由 `office_attachments` 获取完整 ID，不允许猜测或读取别人的附件。

## 功能范围

| 类型 | 读取 | 新建、编辑与转换 |
|---|---|---|
| DOCX | 段落、表格、页眉页脚 | 新建段落/标题/表格，替换文字、改段落和表格单元格；转 PDF/DOC/ODT 等 |
| DOC / ODT | 先由 LibreOffice 转换再读取 | 转为 DOCX 后编辑；原文件保留 |
| XLSX / XLS / ODS | 多工作表、分页行列、公式或缓存值 | XLSX 写值/公式/格式/冻结/筛选/柱线图；LibreOffice 重算、转 PDF/CSV/旧格式 |
| PPTX / PPT / ODP | 幻灯片文字、表格、备注 | 新建标题/要点/备注，替换文字，另存；旧格式转换及 PDF 导出 |
| PDF | 逐页文字、表格提取；扫描页可 OCR | 新建、合并、抽页、旋转、水印、填写已有表单 |
| PNG/JPEG/WebP/TIFF/BMP | 尺寸、离线文字识别 | 裁剪、缩放、旋转、常见图片格式转换 |
| TXT/MD/CSV/TSV/JSON/HTML/RTF/XML | 文本与常见编码 | 文本/CSV/TSV/JSON 另存，常见格式转文本/Markdown |

“编辑”指上述明确支持的结构化操作。不会声称完整复制 Office：宏、复杂动画、嵌入对象、修订保留、PDF 任意文字重排和安全涂黑未实现；复杂排版需要在 Office 或 PDF 查看器中复核。OCR 是识字，不等同于视觉模型理解图片。Excel 公式写入与重算是不同操作。旧格式/HTML/RTF 中可疑外部资源会拒绝转换。

## 数据与权限

- 本地工作区在本机处理，个人云端工作区在本人 Linux Host 内处理。工具返回的文字会进入当前对话，由本人授权的模型处理。
- 只接受当前工作区相对路径或当前会话已上传附件。写操作服从 DSH 会话的写权限；所有输出另存新文件，不覆盖原件。
- 单文件最多 64 MiB；输出最多 128 MiB；读取分页、文字长度、图片像素和解压大小受限。转换超时会终止本次子进程，不代表任意达到该大小的复杂文件都能处理。
- 宏关闭，外部链接受限，Python 网络调用禁用；Windows 的 LibreOffice 子进程不是完整的 OS 沙箱。云端还受独立容器和网络隔离保护。不要把这些限制解释成可以安全执行任意恶意文件。
- 不把公司 IAM / TokenKey 密钥传给办公子进程。第三方来源、许可证及固定依赖见 `THIRD-PARTY.md` 和 lock 文件。

## 升级边界

办公引擎依赖、OCR 模型及转换器都有独立清单。升级 DSH 时只检查 `dev-local/dsh/office-adapter` 的工具、工作区、附件和会话权限契约，并跑适配器和真实 Host 探针。协议和办公引擎不需要随 DSH 重写；如果上游接口不兼容，仍需调整薄适配器并验证，不能保证任意新版本零修改。

Windows 转换器只保留中英文界面资源和英文拼写词典，仍能处理 Unicode 文档。Linux 使用固定镜像中的 Debian 转换器；两平台均以真实格式测试记录为准。公司 IAM、个人 TokenKey 的真实联调和服务器容量不包含在本地离线文件测试中。
