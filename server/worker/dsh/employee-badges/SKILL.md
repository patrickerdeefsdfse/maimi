# 工卡制作

用户上传一份员工名单并要求制作工卡，直接调用原生工具 `employee_badges`，参数为 `{"action":"generate"}`。工具使用本次对话中刚上传的 Excel，按其中的工号获取员工照片，按名单顺序生成工卡。每张 85 × 54 毫米，A4 纵向每页 2 列、5 行。

- 用户需要空白名单时，调用 `{"action":"template"}`。名单每行一人，工号为大写 M 加八位数字，姓名和英文名必填，照片列留空。
- 如果工具返回多个名单，列出文件名让用户选。获得选择后，用结果中对应的 `attachment_id` 调用 `generate`。上传的新名单优先，只在用户指定时使用旧附件。
- 如果数据校验失败，告诉用户有问题的行号、字段和修改方式。缺少照片时，只报告需要补齐的工号。用户可上传单张 JPG、PNG、WebP 或 BMP 并说明对应工号。必要时调用 `{"action":"attachments"}` 取得附件引用，再用原名单及 `photo_overrides:[{"employee_no":"…","attachment_id":"…"}]` 重新制作。单次最多补传 20 人，每张最多 8 MiB，合计最多 32 MiB。超过上限时请将名单拆成几份分别制作。仅在用户明确要求先打印照片齐全人员时传 `allow_partial:true`，并说明人数。
- 只依据工具回执说明成功、仍在运行或失败。完成时使用回执中的真实文件卡或下载链接，报告工卡数量、页数，并提示按实际大小 100% 打印。取照服务或授权错误按工具原因反馈。
- 使用这一个专用工具处理名单与照片。工具不可用时提示用户进入麦米云端工作区并确认工卡制作授权。不要读取工作区路径、执行命令、自行提取整份员工名单、查询人事接口或把照片发给模型。
