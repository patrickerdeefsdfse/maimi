              制作插件包

              从下方示例开始，将文件直接放在 ZIP 根目录。每次修改内容都使用新的版本号，保留相同的插件标识。

              工作技能

              适用于网页版和桌面版。用 UTF-8 编写 SKILL.md，说明适用场景、输入和执行步骤。

              下载周报技能示例

              桌面原生插件

              仅在桌面端运行。包内包含 manifest.json、package.json 和 index.mjs。入口导出 apply(ctx)。

              下载桌面插件示例

              填写 manifest.json

              plugin_key
              以小写字母开头，用小写字母、数字和单个连字符组合，最多 64 个字符，例如 weekly-summary。
              version
              使用三段数字版本号，例如 1.0.0。原生插件的 package.json 也应使用这个版本。
              name、description
              员工看到的名称和用途说明。
              kind
              工作技能填 skill，桌面原生插件填 native。

              发布与分发

              1. 在“版本管理”上传 ZIP，点击“预检”查看检查结果。包中只放必需文件，凭据留在公司服务配置中。
              2. 原生包使用 ES 模块，不带依赖、安装脚本或 node_modules。请将该版本的 SHA-256 交给运维，登记到网关及目标桌面版本的受信清单。网页预检核对网关清单，桌面加载时会核对本机清单。
              3. 点击“发布”，在“授权与分发”输入工号并分发。可分别查看网页和桌面的最近回执，以及“操作记录”中的操作人和时间。
