# 麦米宿主监控采样器候选

状态：本地实现和合成测试，未安装到公司、未设置自动启动，不改变任何现有容器、数据库或私有配置。它为监控后台提供可信来源的资源元数据，不直接开放 HTTP 接口，也不授予员工 Docker 或宿主机权限。

## 实际采集范围

`Collector.sample()` 仅访问本机固定 Docker socket，命令和投影逐项白名单化：固定项目/受管标签的容器 ID、状态、启动时间、重启次数、health/OOM 标志及两个归属标签；不会读取完整 inspect、环境变量、命令行、日志或业务文件。它不会在容器内部 exec，不会启动、停止或重启容器。

每次 Docker 调用显式设置 `--config /opt/maimi-monitor/docker-empty-config`，不使用 Docker 默认家目录配置。该固定目录必须由操作员预建为 root:root、0555 且完全为空，路径组件不允许符号链接，父目录必须受 root 控制；采样器只检查目录元数据和是否存在目录项，不打开配置文件内容。目录缺失、权限不符或非空时拒绝运行 Docker CLI，不回退到 `/root/.docker` 或环境变量。真实 Docker 合成验证使用独立 root 所有的空目录代替固定安装路径，执行后确认仍为空并清理。

宿主读取 `/proc/meminfo`、`/proc/stat` 和两个固定磁盘的容量。容器读取宿主 PID 对应的 cgroup v2：CPU 累积微秒和配额、内存当前/上限/事件、进程线程计数当前/上限/事件、块设备 IO 累计字节/操作数；`/proc/PID/net/dev` 提供网络命名空间累计收发字节和包数，不输出接口名或地址。采样前后确认 PID 起始时刻、cgroup inode 和 Docker 实例状态，变化时丢弃这一容器的测量。

每个容器都保留真实不可变 ID。`owner_ref` 只是受管标签中的 workspace UUID 去掉连字符，**不是可信员工工号**；后台必须再次查询数据库核实归属。共享服务没有 owner_ref。多实例全部保留，不按 Docker 返回顺序选一台冒充当前服务。

字段和单位严格定义在 `sample.schema.json`，额外字段不被允许。`collected_at` 是 Unix 秒；`monotonic_ns` 只在同一个 collector_instance 内比较。首次速率、计数重置、容器/采样器重启、超过 300 秒的间隔都返回 null。CPU `cores=使用微秒增量/间隔秒/1e6`，0.5 表示平均使用半个 CPU 核心；累计使用量不是 CPU 使用率。不限额与未采到都可能是 null，另由 limit_unlimited 区分。

IO 是内核报告的块设备计数总和，不等于应用层业务字节。网络计数属于网络命名空间；host 网络不采集，已知共享命名空间不产生个人速率，不能当作员工账单或累计求和。未知字段为 null，合法空 IO 统计才是实测零。

Linux 接口语义依据：[cgroup v2 官方文档](https://docs.kernel.org/admin-guide/cgroup-v2.html)、[/proc 官方文档](https://docs.kernel.org/filesystems/proc.html)。

## 缓存、时限与存储计量

采样器将上一份完整结果保存在自己内存中，调用者修改返回值不会改变下一次差分基线。默认工作循环每 15 秒采样，单次预算 10 秒，Docker 子进程单次最多 4 秒且双管道输出合计上限 2 MiB。最终快照超过 120 秒应显示陈旧；Docker 失败时 `coverage.docker=unavailable`，空列表代表没有测量，不能显示为零人/零使用。

`StorageCache` 可选开启，默认的直接 stdout 采样不启用目录计量；daemon 候选启用它。计量只遍历已验证 owner/local driver 的 state/files 卷目录元数据，只打开目录 FD，普通文件只 stat，符号链接不会跟随。每轮最多一位 owner，最多 0.5 秒、20 万目录项，成功结果 30 分钟后才重采、1 小时过期。预算耗尽显示未知或保留带原时间戳的旧值，不将不完整计量作为 0，也不会紧接着无限重试。存储是逻辑体积估算，不代表磁盘物理占用或一致性备份。

离线 owner 也有 owner_storage 记录，后台可以在数据库验证归属后显示。卷重新创建/创建时间变化会使旧缓存失效。首次全体 owner 的存储值需要逐轮积累，并非一次把所有业务目录扫描完。

## 后台接线

`cache.publish_cache()` 只向操作员预建的 root:10001/0750 监控目录发布固定 `latest.json`，文件 root:10001/0640、regular、single-link；路径组件 no-follow。先写独占临时文件，fsync 后原子替换，再同步目录。它只写监控自己的元数据文件，不写业务文件或服务配置。`daemon.run()` 保持 root0600 的排他锁，防止两个采样循环同时写同一缓存目录；退出释放锁，不操作服务。

后台仅以只读挂载访问此目录，并经 IAM 鉴权、开发者白名单与数据库归属核验后输出必要汇总。缓存目录路径来自服务配置，不能来自用户 HTTP 请求。collector_instance 会在进程重启后变化，sequence 从 0 开始；后台应按采样器代际或自己的持久序列消费，不能永久拒绝重启后的新样本。采集器不提供模型 token、Office 任务数或桌面本地遥测；这些需由各自经过鉴权的 producer 提供，未接入就显示未知。
