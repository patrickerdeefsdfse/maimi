| 能力 | 本次选择 | 验证要求 |
| --- | --- | --- |
| 对话、推理、工具事件、子代理、任务展示 | 完整新版原生组件 | 实际启动、原生事件及取消，避免混入旧 bundle |
| 插件管理、技能、文件变更、统计、主题 | 新版原生优先 | 清退已过期社区适配，保留用户配置备份 |
| Web 连接及重连 | 原生传输；IAM 登录寿命仍由企业网关负责 | 断线恢复、身份过期与权限撤销分开测试 |
| 桌面启动、窗口、原生目录和设备能力 | 官方 desktop 结构 | 接入公司 IAM、模型与更新渠道后才能发布 |
| 公司模型、IAM、MES、物流、工卡、会议等 | 保留企业服务 | 不绕过员工权限或将服务端凭据交给模型 |
| service | 保留独立 broker 与 IP/密码连接区域 | 新版真实聊天视图展示、输入、同会话连接和状态恢复 |

## 顺序与交付

1. 从 GitHub 已发布的 3e69e21 快照建立独立候选，修健康检查与可复现构建缺口。
2. 完整安装并锁定新版依赖；企业代码通过独立插件与配置加载，旧 DSH 文件覆盖不带入新运行时。
3. 真实本地运行时启动及浏览器测试，合成身份/文件/任务验证；历史数据用副本演练，不直接让新写入器操作公司历史。
4. 集成 Windows 桌面公司登录和模型策略，验证启动/本机能力/企业入口/更新渠道。
5. 生成来源清单、回退边界、检查与维护包，审核后通过原有堡垒机流程部署。不得用健康 READY 代替业务验收。

此前新用户的公司只读连接检查按用户安排留到周一；不能把上游重连修复直接认定为该账户问题的根因。r63 修复融入本次新版候选；r59/r61/r62/r63 冻结文件保持不变。GitHub 主分支当前 3e69e21，不用未完成的升级替换正式快照。
