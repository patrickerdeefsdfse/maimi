# 未接入原生运行时的候选

本目录用于独立准备认证失效恢复逻辑，不被当前 `entry_app.py`、原生 DSH 或已发布安装包加载。不能把这里的单元测试当作服务器续期、原生重连或聊天恢复通过。

`renewal-controller.mjs` 通过显式依赖注入核验身份、合并刷新请求、请求重连并处理身份变化。`renewal-browser.mjs` 是浏览器适配候选，接入公开的 connection.state 订阅、页面恢复事件、Web Locks 和 BroadcastChannel；两者均不包含原生插件注册、退出或部署。

浏览器候选对事件检查设置默认15秒冷却；连续3轮失败暂停自动检查，手动检查或页面重新恢复可以重新尝试。没有事件时不会自行循环发请求。跨标签仅广播实际刷新成功的无凭据信号，接收页独立核验身份。锁或通知能力缺失时禁止自动刷新，不无锁降级。每轮AbortSignal取消排队锁，销毁或超时后的迟到刷新响应不再广播。候选不访问、缓存或重放聊天RPC。

接入前需要确认原生连接服务与 RPC 中止语义。集成必须从可信页面身份初始化 expectedIdentity，在身份变化时离开旧页面，在卸载时销毁协调器。跨页通知不包含身份凭据，收到通知的一方自行复核。RPC 请求不能因恢复而自动重发。

运行候选测试：`node --test ../tests/renewal-controller.test.mjs ../tests/renewal-browser.test.mjs`（本目录）。只使用合成响应和浏览器替身，不访问公司服务。2026-09-17主线程独立验证52/52通过（控制器31、浏览器适配21）；这不是实际浏览器锁、原生重连或现场续期验收。

当前线上功能与验收状态以 `codex-context/README.md` 为准。
